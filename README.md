# myGame — kho thiết kế game thử

Nơi đưa MỌI thiết kế game lên để **thử trước** (trên máy soạn, TOMKO, iPad…) rồi mới đưa vào app/web chính
(AWord, myActivity…). Kho công khai qua GitHub Pages: https://andrewclasses-01.github.io/myGame/

⛔ Không đặt dữ liệu học sinh ở đây (kho công khai).

```
myGame/
  index.html          trang mục lục (danh sách GAMES ở cuối file — game mới thêm lên ĐẦU mảng)
  rocket-race/        Rocket Race · Fight 3D (Three.js)
    index.html        chọn mẫu
    mau-*.html        từng bản mẫu (mau-2b-duoi-theo-tomko.html = bản thầy chọn 26/9/2026)
    core/             lõi 3D dùng chung của các mẫu
```

## Quy ước
- Mỗi game **một thư mục riêng**, tự chạy được (không phụ thuộc thư mục game khác).
- **Bản mới = tên file mới** — không ghi đè bản cũ để còn so sánh.
- Làm xong: cập nhật danh sách trong `index.html`, commit + push. Pages lên mạng sau vài phút (nhớ Ctrl+Shift+R).
- Game chỉ được đưa vào app/web chính SAU KHI thầy thử ở đây và nói "ok".
